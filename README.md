# Sistema de Gestão Reprodutiva Bovino

Projeto integrador desenvolvido para as disciplinas de **Análise e Projeto de Sistemas (APS)** e **Linguagem de Programação Orientada a Objetos (LPOO)**.

**Curso:** Bacharelado em Ciência da Computação (IFSul)  
**Período:** 2026/1  

---

## O Projeto
O sistema consiste em um software de gestão e controle reprodutivo para rebanhos bovinos. Aplica Padrões de Projeto (como DAO e State) visando um código limpo e escalável, integrando uma camada de apresentação (View) intuitiva em Tkinter que separa perfeitamente as regras de negócio da interface gráfica e realiza a persistência em um banco de dados PostgreSQL.
